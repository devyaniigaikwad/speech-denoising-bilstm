# Speech Denoising Using BiLSTM Mask Estimator

This project implements a deep-learning-based speech denoising system using a Bidirectional Long Short-Term Memory (BiLSTM) mask estimator in MATLAB.

The system processes noisy speech in the time-frequency domain using Short-Time Fourier Transform (STFT), estimates a speech mask using the BiLSTM model, and reconstructs the enhanced speech signal using inverse STFT.

## Key Features

- STFT-based speech processing
- BiLSTM-based spectral mask estimation
- Speech enhancement from noisy recordings
- Objective evaluation using SNR, SI-SDR and SegSNR
- MATLAB implementation
- Spectrogram and performance analysis
